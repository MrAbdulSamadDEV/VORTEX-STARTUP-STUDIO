# VORTEX — Creative Developer Studio

A responsive, futuristic developer toolkit built with plain HTML, CSS, and JavaScript.

## Features
- Responsive neon/glassmorphism interface
- Live toolkit search and theme toggle
- Text transformation, JSON formatting, word statistics, Base64 encoding, random password generation, and scratchpad
- Copy-to-clipboard support
- No frameworks, build tools, external fonts, APIs, or API keys required
- Accessible labels, live output announcements, and reduced-motion support

## Run locally
1. Clone or download this repository.
2. Open `index.html` in a modern browser.

No installation or build step is required.

## Deploy free with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait for GitHub Pages to publish, then use the URL shown on the Pages settings screen.

## Privacy
All tool processing happens locally in your browser. The site does not send your input to a server.
